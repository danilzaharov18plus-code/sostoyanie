# Состояние — дневник лечения

Веб-приложение для iPhone, которое устанавливается на главный экран. Без сервера и зависимостей; данные хранятся только в телефоне (localStorage).

- `index.html`, `styles.css`: разметка и стили (светлая и тёмная тема)
- `app.js`: логика, экраны, опросники PHQ-9 и GAD-7, напоминания (.ics)
- `charts.js`: SVG-графики
- `report.js`: PDF-отчёт для врача (canvas → JPEG → PDF)
- `sw.js`, `manifest.webmanifest`: установка и работа офлайн

Локальная проверка: `python3 -m http.server 8765`, затем открыть http://localhost:8765.
На iPhone нужен HTTPS-хостинг (например, GitHub Pages). После изменений повышайте версию `CACHE` в `sw.js`.
